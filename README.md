JavaScript practice with DOM changes events a calculator and a to-do list

Website
https://arnur-kozhabergen.github.io/web.asmnt5/

Open index.html in a browser or use the website link
Use the navigation links to open each part
No installation is needed

Basics covers tasks 0 and 1
A welcome alert appears when the page opens
Press F12 and open Console to see the name group variables arithmetic and joined strings

DOM covers tasks 2 to 4
Use the buttons to change text background and font size
Add Item adds a list item and Remove Item removes the last one

Events covers tasks 5 to 7
Move the mouse over the box and then away
Type in the input to see the text update on keyup
Enter two numbers choose an operation and click Calculate
Division by zero shows a message

To-do list covers task 8
Enter a task and click Add Task
Tick its checkbox to cross it out or untick to undo
Click Delete to remove it
Tasks are stored in an array and disappear after reloading or closing the page
